## Что в текущей версии не заявлено (N/A)

- Вакансии с откликами, регулярные задания — убраны из сборки (README, «Известные ограничения»).
- Настоящий провайдер ФСП ID (Keycloak) — не реализован; проверен только демо-провайдер.

- Демо-приглашение новому кандидату от демо-компании — не реализовано.

## Уровни проверки

- **UI** — действия во встроенном браузере на реальном стенде с реальным API (регистрация, формы, тест, приглашение, ответ).
- **API / API+DB** — запросы под отдельными сессиями ролей (`tools/qalib.py`), состояние сверено запросами к PostgreSQL стенда.
- **integration (независимое исполнение)** — ключи заданий перепроверены исполнением условия (SQLite, отдельный процесс Python).
- **unit** — прямой вызов функции оценивания; ссылки на существующие pytest там, где границу нельзя воспроизвести на стенде.

## Ограничения проверки

- Независимых браузерных контекстов во встроенном браузере нет: роли менялись выходом и входом. Независимость ролей на уровне API обеспечена отдельными сессиями.
- Буфер обмена панели браузера прочитать нельзя; скриншоты панели недоступны, когда она скрыта, — доказательства интерфейса сохранены текстом страницы и состоянием DOM.
- Лимит регистраций (50 в час с адреса) исчерпан на первом наборе; дальше проверочные аккаунты создавались фикстурой (`qalib.fixture_user`), что помечено в `test-data.md`.
- Часы сервиса сдвигались штатным механизмом ведущего; границы «секунда до/после» на стенде не воспроизводятся и закреплены только unit-тестами.
- Нагрузочные проверки не выполнялись. Развёртывание и публикация изменений не выполнялись.
